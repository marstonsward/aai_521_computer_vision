## Part 1 - Feature Extraction

### Setup

- Read image from `Assignment4_pic1.jpg` (©thispersondoesnotexist)
- Create two versions: RGB (colorful) and grayscale
- Save grayscale as `pic1_gray.jpg`
- Note: Images may load as BGR by default, convert to RGB

### Tasks

#### a) SIFT (Scale-Invariant Feature Transform)

- Introduced by David Lowe (2004)
- Method for extracting distinctive invariant features
- Detects features irrespective of orientation and size
- **Outputs**: Two versions - one with sizing and one without

#### b) FAST (Features from Accelerated Segment Test)

- Proposed by Edward Rosten and Tom Drummond (2006)
- Corner detection method for feature point extraction
- Popular in real-time video processing
- **Outputs**: Two versions - with max suppression and without

#### c) ORB (Oriented FAST and Rotated BRIEF)

- Proposed by Rublee, Rabaud, Konolige, and Bradski (2011, OpenCV Labs)
- Robust to distortion and noise
- Implement ORB feature extraction

#### d) Feature Matching

- Compare colorful and grayscale images
- Print number of matching points between the two images
